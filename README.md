This project is a simple hangman game that I have made using CSS, HTML, and JavaScript.

The game uses a canvas to display the hangman character and uses a textbox with a submit button to handle inputs.

To play enter one text character into the text box then click enter or the submit button to check if the letter is in the word. The game will reveal the parts of the word that has that letter in it and if it is not in the word then a part of the hangman will appear. you only get 5 strikes before you lose if you don't guess a letter in the word.

If you lose the word will be revealed.
